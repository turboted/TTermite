# Reconstructed release notices

These current-date reconstructed sources retain the original program and component licenses. Original license, copyright and NOTICE evidence for bundled fonts, glyphs, themes and cryptographic dependencies is included in `Berth/Resources/Legal/`; font licenses also accompany the font files when present. This notice backport does not introduce later runtime features into earlier stages.

The original development source and the new release source are linked in `source-rebuild-map.json`. No original development commit or existing remote tag is moved. New App versions equal their release versions. Local verification reports are excluded from source history.
