# TTermite v1.19.0

TTermite v1.0.0 基础功能总览

- [新增] 建立独立 macOS 终端 App，使用 TTermite 的 bundle、数据库与 Keychain 命名空间；支持 macOS 15 以上，与 Berth 数据分开保存。

- [新增] 本地 Shell 可选择程序与工作目录，使用 PTY 执行交互命令；关闭 App 不会保留仍在运行的进程。

- [新增] SSH 支持密码、私钥、agent 与交互验证、主机密钥确认、跳板与代理、连接存活检测及自动重连；实际连接仍取决于服务器与网络。

- [新增] 主机侧栏支持分组、快速连接、搜索、ssh_config 导入及本地目录书签，可集中管理常用目标。

- [新增] 多标签终端支持水平与垂直分屏、焦点切换及广播输入；广播会将输入发到多个窗格，需要确认各窗格的目标。

- [新增] 终端支持 ANSI 色彩、字体与字号、光标形状与闪烁、选择复制、中键粘贴、主题及透明外观；基础版尚未加入后续 Nerd Font 包。

- [新增] 可搜索终端文本、跳到前后命令与复制上一命令输出，并支持工作目录标记；命令导航依赖 Shell 提供集成标记，尚无后续持久化搜索数据库。

- [新增] SFTP 面板提供远程目录浏览、上传下载、拖放及外部编辑流程；远程权限、文件格式与网络状态仍限制操作。

- [新增] SSH 通道提供本地、远程及动态转发，可保存转发配置；须由服务器允许并避免本地端口冲突。

- [新增] 服务器信息、CPU／内存等资源监控与仪表盘可显示多台主机状态，另提供 Docker 面板与 Wake-on-LAN；数据依赖远程工具、权限和网络环境。

- [新增] 可保存工作区／会话模板并重新连接，设置启动恢复标签页与工作目录；本版不包含后续完整窗格和画面快照恢复。

- [新增] 命令片段可重复执行常用操作，输出触发器可按匹配条件执行动作，并支持会话记录与后台命令／响铃通知；功能需要相应设置与系统通知权限。

- [新增] 命令面板、键盘快捷键与菜单栏入口提供快速切换和常用操作，可选择主机可达性探测。

- [新增] 私钥与密码保存在 Keychain，支持使用私钥前的 Touch ID／密码确认、多行或危险命令粘贴保护及隐私遮罩；保护措施不取代用户核对命令。

- [新增] 主机、分组与转发等结构可导入／导出备份，备份不包含 Keychain 密码、口令与私钥；恢复后需重新提供凭据。

- [新增] 原基础来源包含 iCloud 同步设置与数据模型，能否使用取决于签名、entitlement 及账号；本次 ad-hoc 重建不宣称云同步已可用。

- [新增] 原基础来源包含 AI 助手、服务商／模型设置、对所选内容提问与建议命令流程；需要兼容服务及凭据，这是后续删除前的历史功能。

- [新增] 界面包含当时的英文与简中资源、系统语言选择及关于／致谢页；繁中完整支持属于后续版本，原继承的更新检查不代表可自动合并上游代码。

- [其它] 这是 2026-10-30 从最早 TTermite 来源重新建立的 v1.0.0，不是旧成品改标；源代码、依赖及许可对照见 source-rebuild-map.json。构建检查与版本政策属于重建基础设施，独立验证与公开发布另行记录，未经公证，也不宣称实机 SSH、Docker、云端、AI 服务或 Intel 执行已验收。
