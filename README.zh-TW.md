# TTermite v1.4.0

TTermite v1.0.0 基礎功能總覽

- [新增] 建立獨立 macOS 終端 App，使用 TTermite 的 bundle、資料庫與 Keychain 命名空間；支援 macOS 15 以上，與 Berth 資料分開保存。

- [新增] 本機 Shell 可選擇程式與工作目錄，使用 PTY 執行互動命令；關閉 App 不會保留仍在執行的程序。

- [新增] SSH 支援密碼、私鑰、agent 與互動驗證、主機金鑰確認、跳板與代理、連線存活偵測及自動重連；實際連線仍取決於伺服器與網路。

- [新增] 主機側欄支援群組、快速連線、搜尋、ssh_config 匯入及本機目錄書籤，可集中管理常用目的地。

- [新增] 多分頁終端支援水平與垂直分割、焦點切換及廣播輸入；廣播會將輸入送到多個窗格，需確認各窗格的目的地。

- [新增] 終端支援 ANSI 色彩、字型與字級、游標形狀與閃爍、選取複製、中鍵貼上、主題及透明外觀；基礎版尚未加入後續 Nerd Font 套件。

- [新增] 可搜尋終端文字、跳到前後命令與複製上一命令輸出，並支援工作目錄標記；命令導覽依賴 Shell 提供整合標記，尚無後續持久化搜尋資料庫。

- [新增] SFTP 面板提供遠端目錄瀏覽、上傳下載、拖放及外部編輯流程；遠端權限、檔案格式與網路狀態仍限制操作。

- [新增] SSH 通道提供本機、遠端及動態轉送，可保存轉送設定；須由伺服器允許並避免本機連接埠衝突。

- [新增] 伺服器資訊、CPU／記憶體等資源監看與儀表板可顯示多台主機的狀態，另提供 Docker 面板與 Wake-on-LAN；資料依賴遠端工具、權限和網路環境。

- [新增] 可保存工作區／會話模板並重開連線，設定啟動還原分頁與工作目錄；本版不包含後續完整窗格和畫面快照還原。

- [新增] 命令片段可重複執行常用操作，輸出觸發器可依比對條件執行動作，並支援會話記錄與背景命令／響鈴通知；功能需相應設定與系統通知權限。

- [新增] 命令面板、鍵盤快捷鍵與選單列入口提供快速切換和常用操作，可選擇主機可達性探測。

- [新增] 私鑰與密碼保存於 Keychain，支援使用私鑰前的 Touch ID／密碼確認、多行或危險命令貼上保護及隱私遮罩；保護措施不取代使用者核對命令。

- [新增] 主機、群組與轉送等結構可匯入／匯出備份，備份不含 Keychain 密碼、密語與私鑰；還原後須重新提供憑證。

- [新增] 原基礎來源含 iCloud 同步設定與資料模型，能否使用取決於簽章、entitlement 及帳號；此次 ad-hoc 重建不宣稱雲端同步已可用。

- [新增] 原基礎來源含 AI 助手、供應商／模型設定、選取內容提問與建議命令流程；需要相容服務及憑證，這是後續刪除前的歷史功能。

- [新增] 介面含當時的英文與簡中資源、系統語言選擇及關於／致謝頁；繁中完整支援屬後續版本，原繼承的更新檢查不表示可自動合併上游程式碼。
